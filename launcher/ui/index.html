    Nexus and manually downloaded archives
    
            
    
              Nexus controls automatic download eligibility. You can also open
              the pinned file on Nexus, download it yourself and import the
              archive. Its SHA-256 must match the server manifest. This
              candidate supports ZIP, 7z and RAR archives. Encrypted and
              multipart archives are unsupported.
            
    
            
    
              
              
              
              
            
    
            
    
            
    
              
              
              
              
            
    
            
    
              UMO opens Nexus sign-in in your browser. Free accounts approve
              each file with Mod manager download / Slow download; Premium
              eligibility is checked by UMO. Fetcher verifies and installs the
              exact server files. Manual import also works. If Nexus says the
              download is starting but nothing happens, click its “Start
              download manually” link to send it to the helper.
            
    
            
    
              
              
            
    
            
    
              Browser links are opt-in: this changes this Windows user's NXM
              handler, which may currently belong to another mod manager.
              Restore it here when finished. Only the file currently requested
              by Fetcher is accepted.
