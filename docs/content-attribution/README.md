These are local, version-controlled copies of the artist/source/license/adaptation notices shipped
with Fetcher content. They are content records, independent of the general-purpose launcher UI.

The full records preserve original model links, author links where provided, CC BY 4.0 references
and descriptions of the adaptations. The Studio license text is retained alongside its attribution.
The content archive continues to ship these same notices under Data Files/FetcherStudio and
Data Files/FetcherVehicles. Removing the launcher tab does not remove notices from distributed assets.
Launcher library and image notices remain in launcher/THIRD_PARTY_NOTICES.txt and the built package.

## Future display placement

Choose a content-specific home before the broader game-content rollout. Candidates are an in-game
FETCHER STUDIO Help/Credits view and a selected server profile's content details. A general launcher
should not present one server's models as launcher-wide credits. No replacement screen is selected
or implemented yet; source/license records remain available independently of that decision.

Update these records together with the content's source attribution when models or adaptations change.
